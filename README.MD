# HashTrack

HashTrack is a Visual Studio Tools for Office (VSTO) plugin for Microsoft Outlook, developed as a part of my bachelor thesis at VŠB - Technical University of Ostrava. This plugin enhances Outlook by introducing the ability to search for hashtags across various Outlook artifacts such as emails, appointments, and tasks. By leveraging the power of hashtags, HashTrack aims to streamline the organization and retrieval of Outlook items, making it easier for users to manage their information efficiently.

## Features

- **Hashtag Search**: Quickly find Outlook items containing specific hashtags.
- **Custom Tagging**: Add hashtags to Outlook items for better organization.
- **Seamless Integration**: Works within the Outlook interface for a cohesive experience.

## Installation

1. Download the latest release of HashTrack.
2. Run the installer and follow the instructions to add HashTrack to your Outlook.

## Usage

Once installed, HashTrack integrates directly into your Outlook sidebar, providing a simple search interface to query hashtags.
